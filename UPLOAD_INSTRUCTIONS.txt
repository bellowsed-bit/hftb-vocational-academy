HOW TO UPDATE GITHUB
1. Unzip HFTB_Academy_Mobile_Fix_2026-09-08.zip on your computer.
2. Open https://github.com/bellowsed-bit/hftb-vocational-academy
3. Make sure the branch selector says main.
4. Choose Add file, then Upload files.
5. Open the unzipped folder. Select everything INSIDE the folder and drag it onto GitHub.
   Do not upload the ZIP itself, and do not place the whole folder inside the repository.
6. GitHub will show existing files as changed and new files as added. This is expected.
7. Enter this commit message: Fix phone layouts and final course navigation
8. Select Commit directly to the main branch, then choose Commit changes.
9. Wait for the green GitHub Pages deployment check. Then open:
   https://bellowsed-bit.github.io/hftb-vocational-academy/
10. On the phone, close the old page and reopen it. If the old layout remains, clear the browser cache or use a private/incognito tab once.
