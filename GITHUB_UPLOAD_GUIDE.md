# Homes for the Brave Vocational Services Academy
## Beginner Instructions: Upload the Complete Website Update

This package contains the complete Academy website, including the new public **Sources & References (PDF)** button and its PDF. You do not need a separate link, branch, or backup package.

## Upload the Package to Your Existing Repository

1. Download `Homes_for_the_Brave_Vocational_Academy_Complete_GitHub_Update.zip`.
2. Open your computer's **Downloads** folder.
3. Right-click the ZIP and select **Extract All**.
4. Select **Extract**.
5. Open the extracted folder.
6. Sign in to GitHub and open your existing `hftb-vocational-academy` repository.
7. Confirm the branch displayed near the top is `main`.
8. Select **Add file**, followed by **Upload files**.
9. Return to the extracted folder and select everything inside it.
10. Drag the selected folders and files into GitHub's upload area.
11. Wait for GitHub to finish processing the files.
12. Enter this commit message:

    `Add public Academy sources and references page`

13. Select **Commit directly to the main branch**.
14. Select **Commit changes**.

## Important

- Upload everything **inside** the extracted folder, not the ZIP itself.
- Do not place the extracted folder inside the repository as another folder.
- Do not delete or change the repository's `.github` workflow folder, `CNAME`, or Pages settings.
- Matching website files will be updated. The reference PDF will be added inside `public`.

## Confirm the Website Update

1. Open the repository's **Actions** tab.
2. Wait for the newest deployment to show a green checkmark.
3. Open the public Vocational Services Academy website.
4. On the homepage, confirm the gold **Sources & References (PDF)** button appears beside the two course buttons.
5. Select the button and confirm the PDF opens without requesting a GitHub or ChatGPT sign-in.
6. Confirm Work-Life Balance and Communication Skills still open normally.

The website remains public through the same GitHub Pages address. Visitors can now reach the reference document directly from the Academy homepage.
